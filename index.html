「Joyce and MB 社媒工具」私隱政策

最後更新：2026 年 10 月 24 日

簡介

本私隱政策適用於「Joyce and MB 社媒工具」（下稱「本應用程式」）——一個經 Meta Graph API 連接 Facebook 專頁的內部發佈工具。本應用程式僅由「Tsang Yue, Joyce」專頁的管理員操作，並不向公眾提供任何登入、註冊或互動功能。

我們收集甚麼資料

本應用程式不會收集任何公眾用戶的個人資料。

本應用程式透過 Meta Graph API 讀取及使用的資料僅限於：

  • 操作者（專頁管理員）自己所管理之專頁的內容與互動數據（貼文、留言數、觸及人數等）；
  • 操作者授權時所同意的權限範圍內的專頁資訊。

本應用程式不會讀取、儲存或分享任何非操作者擁有之專頁或個人帳戶的資料。

資料的使用方式

  • 專頁資料僅用於代表操作者發佈內容至其擁有的專頁，以及讀取該專頁的互動統計數據。
  • 本應用程式不會向任何第三方出售、出租或分享資料。
  • 發佈紀錄（貼文內容摘要、時間、貼文編號）僅儲存於操作者本機，作審計用途。

資料的儲存與安全

  • 專頁存取權杖等同密碼，儲存於操作者本機的加密設定檔內，永不公開。
  • 本應用程式不設任何對外資料庫，不會將資料傳送至 Meta 平台以外的任何伺服器。

第三方服務

本應用程式僅依賴 Meta 官方 Graph API 進行操作，並遵守 Meta 平台政策與開發者條款。Meta 的私隱政策請參閱：facebook.com/privacy/policy

資料刪除

由於本應用程式不收集公眾用戶資料，公眾用戶無需向本應用程式提出資料刪除請求。操作者可隨時刪除本機上的設定檔與發佈紀錄，或在 Facebook「應用程式與網站」設定中移除本應用程式的授權。

聯絡方式

如有任何私隱相關查詢，請電郵至：itd@modernbeautysalon.com

政策更新

本政策如有重大修改，將於此頁面更新並註明日期。
